ПРИЛОЖЕНИЕ «ВЕКТОРЕНИЕ И ПРОФИЛЬ СНИЖЕНИЯ A320/A321» — УСТАНОВКА НА iPad

АДРЕС ДЛЯ SAFARI: https://vacuumil.github.io/profile-a320/

ПРИНЦИП РАБОТЫ В ПОЛЕТЕ БЕЗ ИНТЕРНЕТА:
Приложение выполнено по технологии Progressive Web App (PWA). После первого открытия по ссылке в Safari файлы сохраняются в постоянную память iPad и сервис-воркер. В полете интернет не требуется — приложение запускается как обычная программа с иконки на экране «Домой».

------------------------------------------------------------------------
ИНСТРУКЦИЯ ПО УСТАНОВКЕ (1 РАЗ С ИНТЕРНЕТОМ):
1. Загрузите обновленные файлы из этой папки (index.html, sw.js, manifest.webmanifest) в ваш репозиторий GitHub.
2. На iPad откройте Safari и перейдите по адресу:
   https://vacuumil.github.io/profile-a320/
3. Нажмите кнопку «Поделиться» (иконка квадрата со стрелкой вверх в правом верхнем углу Safari).
4. Выберите пункт «На экран „Домой“» (Add to Home Screen).
5. Нажмите «Добавить». На рабочем столе iPad появится иконка «Векторение A320».
6. Запустите приложение с этой иконки один раз при наличии интернета.
7. ВСЁ ГОТОВО! Теперь в полете при включенном «Авиарежиме» открывайте иконку — приложение работает полностью автономно.

------------------------------------------------------------------------
КАК ПОЛЬЗОВАТЬСЯ В КАБИНЕ:
1. Вверху карточка вердикта:
   - 🟢 УСПЕВАЕМ (CLEAN)
   - 🟡 НА ГРАНИ / СНИЖАТЬСЯ СЕЙЧАС
   - 🟠 SPEED BRAKES (выпустить интерцепторы)
   - 🔴 ШАССИ + ИНТЕРЦЕПТОРЫ (выпуск шасси на скорости ≤ 220 kt)
   - ⛔ НЕ УСПЕВАЕМ (дефицит миль, запросить у ATC вектор/орбиту)
2. Рядом отображаются:
   - Требуемая вертикальная скорость (Req V/S) и угол FPA для выхода в глиссаду.
   - Путевая скорость (GS) с учетом ветра и истинной скорости.
   - Запас или дефицит миль по 3 градиентам (Clean 2.5°, +Интерцепторы 3.5°, Шасси+Интерцепторы 4.2°).
3. 4 поля ввода:
   - Track Miles (NM)
   - Высота текущая (ft)
   - Приборная скорость IAS (kt)
   - Ветер (kt, + встречный / − попутный)
   Для быстрой корректировки в болтанке используйте крупные кнопки «±». Для точного ввода нажмите на само число — откроется цифровой блок.
4. Кнопка «Настройки» внизу:
   - Позволяет задать превышение ВПП, угол глиссады (3.0°), массу ВС, VAPP, высоту стабилизации (1000 ft IMC / 500 ft VMC) и температуру воздуха OAT. Все настройки автоматически сохраняются на устройстве.
