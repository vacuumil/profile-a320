ПРОФИЛЬ СНИЖЕНИЯ A320/A321 — УСТАНОВКА НА iPad (РАБОТАЕТ БЕЗ ИНТЕРНЕТА)

ПОЧЕМУ НЕ РАБОТАЛО
Если открыть .html из приложения «Файлы», iPad показывает его в режиме просмотра
(Quick Look), где JavaScript выключен — поэтому кнопки не нажимаются.
Нужно открыть приложение в Safari по ссылке https://… и добавить на экран «Домой».

ШАГ 1. Разместить папку в интернете (один раз, бесплатно) — GitHub Pages
 1. На компьютере зайдите на github.com, зарегистрируйтесь/войдите.
 2. «+» → New repository → имя, например: profile-a320 → Public → Create repository.
 3. «uploading an existing file» → перетащите ВСЕ файлы из этой папки
    (index.html, sw.js, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png)
    → Commit changes.
 4. Settings → Pages → Source: «Deploy from a branch», Branch: main / (root) → Save.
 5. Через 1–2 минуты появится адрес вида https://ВАШ-ЛОГИН.github.io/profile-a320/

ШАГ 2. Установить на iPad (с интернетом, один раз)
 1. Откройте этот адрес в Safari.
 2. Кнопка «Поделиться» (квадрат со стрелкой) → «На экран „Домой“» → «Добавить».
 3. Запустите приложение С ИКОНКИ «Профиль A320» один раз, пока есть интернет —
    оно сохранится в iPad.
 4. Дальше работает в полёте без интернета. Ваши ВПП, ветер, настройки хранятся в iPad.

ОБНОВЛЕНИЕ
 Загрузите новый index.html в репозиторий, в sw.js увеличьте номер версии
 (profile-a320-v3 → v4). При следующем запуске с интернетом приложение обновится.

ВАЖНО
 Вспомогательный калькулятор, не одобренное приложение EFB. Основные средства —
 ND (energy circle), VDEV, PROG. Использование — по политике EFB (РПП (А) 8.17).
