Установка на iPad (работает без интернета)

  1. Откройте ссылку на приложение в Safari (с интернетом, один раз).
  2. Кнопка «Поделиться» → «На экран „Домой“».
  3. Запускайте с иконки «Профиль A320». После первого открытия приложение сохраняется в iPad и работает офлайн; ваши данные хранятся на устройстве.

Файл .html, открытый из приложения «Файлы», показывается в режиме просмотра без JavaScript — кнопки там не работают. Нужен Safari.

Как пользоваться на заходе

  1. Перед полётом: «Настройка» — ВПП (превышение, курс, склонение, угол, TCH, точки), самолёт и скорости с MCDU; «Ветер OFP» — ветер по эшелонам из OFP и ATIS.
  2. На заходе: выберите режим расстояния, коснитесь поля → цифры → OK ▸. Кнопки ± — быстрые поправки.
  3. Ветер «OFP по высотам» — встречная составляющая считается автоматически по высоте и направлению каждого участка пути (даунвинд, база, финал).
  4. Смотрите статус и «План» — последние рубежи (NM до порога), выполнить не позже.

Режимы расстояния

  • До порога — track miles по ожидаемому пути. Ветер — по посадочному курсу.
  • До точки — удаление до точки схемы + её удаление от порога.
  • Даунвинд — смещение от оси, позиция от траверза порога (+ дальше от торца), выход на финал. Путь = (финал − позиция) + смещение + финал.
  • База — до оси по базе + выход на финал.

Модель

Нужно миль = ворота стабилизации + торможение на глиссаде + снижение до высоты перехвата + торможение до скорости перехвата. Градиенты пересчитываются на путевую скорость по ветру. Холод: высотомер завышает ≈ 4×ΔISA×H/1000 (FCTM). Способы: (1) малый газ в текущей конфигурации, (2) + интерцепторы, (3) шасси + механизация + интерцепторы.

Правила (FCTM/FCOM/РПП)

  • Следующая конфигурация — на маневренной скорости текущей + 10 kt, ниже VFE: FLAPS 1 ≈ GD+10, 2 ≈ S+10, 3 ≈ F+10, FULL — ниже VFE FULL.
  • Шасси — обычно с FLAPS 2; при нехватке торможения раньше, ниже 220 kt и до FLAPS 2.
  • Интерцепторы: растёт VLS; убираются в FULL (A320) / CONF 3 (A321).
  • Стабилизация 1000 ft IMC / 500 ft VMC; на 500 ft VAPP −5…+20 kt (РПП (B) 2.2.7).
  • Глиссада сверху: на LOC, L/G + ≥ CONF 2, G/S armed, FCU ALT выше, V/S −1500.

Версия 3.0. Источники: FCOM AFL A320/A321, FCTM, РПП (А), РПП (B).
